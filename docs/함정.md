# Git Reward 함정 기록

> **겪은 것만 적는다.** 이 기록이 그대로 발표 자료의 트러블슈팅이 된다.
> 아직 안 겪었지만 조심할 것들은 `위험포인트.md` 에 모여 있다. 막히면 거기를 먼저 본다.

## 적는 형식

```
YYYY-MM-DD | 파일 | 증상 → 원인 → 해결
```

**한 줄로 적는다.** 길게 쓰지 않는다. 다시 겪었을 때 알아볼 수 있으면 충분하다.
막힌 시간이 아까울수록 적을 가치가 있다. 5분 만에 푼 것도 적어둔다 — 다음 사람은 5분을 안 쓴다.

## 시작 전부터 알고 있던 것

직접 겪은 게 아니라 미리 조사해 둔 것이다. 발표 때 "겪은 것"과 구분하려고 따로 둔다.

- `/stats/contributors` 는 첫 호출에서 **202** 와 빈 응답을 반환한다. 재시도 필수.
- 디스코드 슬래시 명령은 **길드 한정 sync**(`guild=`)로 등록한다. 전역 등록은 반영이 느리다.
- 디스코드는 명령 응답이 3초를 넘기면 실패 처리한다. `await interaction.response.defer()` 를 먼저 호출한다.
- 이미지를 `BytesIO` 로 보낼 때 `buf.seek(0)` 을 빠뜨리면 빈 파일이 전송된다.
- Pillow 에서 한글 폰트를 지정하지 않으면 글자가 네모로 깨진다.
