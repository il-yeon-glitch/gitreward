# config.py

> 설정값을 모아두는 파일. **코드가 아니라 값만 있다.**

## 역할

| | |
|---|---|
| 입력 | 없음 |
| 출력 | 없음 (다른 파일이 `import` 해서 읽어간다) |
| 실행 | 실행하는 파일이 아니다 |

다른 파일 다섯 개가 전부 이 파일을 가져다 씁니다. **숫자와 색은 여기에만 적습니다.**

```
config.py
   ↑  ↑  ↑
stats.py  card.py  web.py
```

## 왜 값을 한 곳에 모으나

밸런스를 조정할 때 **코드를 안 건드려도 되기 때문**입니다.

카드 색을 바꾸고 싶은데 색이 `card.py` 안에 흩어져 있으면, 그림 그리는 코드를 읽으면서 색을 찾아야 합니다. 찾다가 실수로 `draw.rectangle` 의 좌표를 건드리면 멀쩡하던 카드가 깨집니다.

값이 여기 모여 있으면 **동작하는 코드를 열 필요가 없습니다.**

## 1) 능력치 부분 — stats.py 가 쓴다

```python
STAT_NAMES    = {"ATK": "ATK", "DEF": "DEF", "AGI": "AGI", "STA": "STA"}
STAT_WEIGHTS  = {"ATK": 1/50, "DEF": 1/50, "AGI": 2, "STA": 5}
LEVEL_DIVISOR = 8
STAT_MAX      = 99
```

### STAT_NAMES

카드에 찍히는 글자입니다. 왼쪽(키)은 코드가 쓰는 이름이라 **바꾸면 안 되고**, 오른쪽(값)은 화면에 보이는 글자라 바꿔도 됩니다.

```python
STAT_NAMES = {"ATK": "공격력", ...}   # 이렇게 해도 코드는 안 깨진다
```

`card.py` 는 `for key in STAT_NAMES:` 로 순회하므로, **여기 적힌 순서가 카드에 그려지는 순서**입니다.

### STAT_WEIGHTS — 계수

**계수의 방향이 서로 반대인 게 핵심입니다.**

| 능력치 | 원래 데이터 | 크기 | 계수 |
|---|---|---|---|
| ATK | 추가한 줄 수 | 수천 단위 | × 1/50 (**줄인다**) |
| DEF | 삭제한 줄 수 | 수천 단위 | × 1/50 (**줄인다**) |
| AGI | 커밋 횟수 | 수십 단위 | × 2 (**키운다**) |
| STA | 활동한 주 수 | 한 자리 | × 5 (**키운다**) |

원래 데이터의 크기가 제각각이라 그대로 쓰면 ATK만 몇천이 되고 STA는 3이 됩니다. 계수를 곱해 **넷 다 100 안팎의 같은 눈금 위에** 올려놓는 것입니다.

> **나누기를 안 쓰고 곱하기(`1/50`)로 통일한 이유** — 나누는 것과 곱하는 것이 섞여 있으면 사람마다 다르게 구현합니다. 전부 곱셈이면 "계수가 1보다 크면 키우는 것, 작으면 줄이는 것" 하나로 읽힙니다.

### LEVEL_DIVISOR

```
레벨 = (ATK + DEF + AGI + STA) ÷ 8
```

**레벨을 조정할 때 이걸 먼저 만집니다.** 계수를 만지면 능력치 하나만 움직이지만, 이 값은 전체가 한 번에 오르내립니다.

- 레벨이 전체적으로 낮다 → 이 숫자를 **줄인다** (예: 8 → 6)
- 레벨이 전체적으로 높다 → 이 숫자를 **키운다** (예: 8 → 10)

### STAT_MAX

능력치 하나가 넘을 수 없는 값. 넷 다 채우면 `396 ÷ 8 = Lv.49` 라, 기획서 목표 구간(20~50)의 위쪽에 맞습니다.

## 2) 카드 부분 — card.py 가 쓴다

### 색

```python
CARD_BG     = (18, 18, 20)     # 배경
CARD_ACCENT = (255, 176, 46)   # 강조색 — 막대와 레벨에만
CARD_TEXT   = (235, 235, 240)  # 본문 글자
CARD_SUB    = (130, 130, 140)  # 흐린 글자
CARD_BAR_BG = (38, 38, 44)     # 막대의 빈 부분
```

숫자 3개는 순서대로 **빨강, 초록, 파랑**이고 각각 0~255 입니다. `(18, 18, 20)` 은 셋 다 낮으니 거의 검정, 파랑이 2 더 높아서 아주 살짝 푸른 회색입니다.

**강조색은 하나만 씁니다.** 여러 개 쓰면 고르는 데 시간이 가고 결과도 지저분해집니다.

> `web.py` 도 이 색들을 가져다 씁니다. `css()` 함수로 `rgb(18, 18, 20)` 형태로 바꿔서 씁니다. 그래서 **여기만 고치면 카드와 웹페이지 색이 같이 바뀝니다.**

### 위치와 크기

```python
CARD_WIDTH = 600      CARD_HEIGHT = 900     CARD_PADDING = 50
AVATAR_SIZE = 200     AVATAR_TOP = 70
NAME_TOP = 310        LEVEL_TOP = 370
STAT_TOP = 470        STAT_ROW_HEIGHT = 95   BAR_HEIGHT = 20
```

`~_TOP` 은 전부 **카드 위에서부터의 거리(픽셀)** 입니다. 아래로 갈수록 숫자가 커집니다.

```
     0 ┌──────────────┐
    70 │    ●●●●      │  AVATAR_TOP
       │    ●●●●      │  (AVATAR_SIZE = 200)
   310 │   octocat    │  NAME_TOP
   370 │    Lv. 24    │  LEVEL_TOP
   470 │ ATK      45  │  STAT_TOP
       │ ▬▬▬▬▬░░░░░░  │
   565 │ DEF      12  │  STAT_TOP + STAT_ROW_HEIGHT
       │ ▬░░░░░░░░░░  │
   660 │ AGI      66  │  + 95
   755 │ STA      35  │  + 95
   900 └──────────────┘
```

능력치를 하나 늘리고 싶다면 `STAT_ROW_HEIGHT` 를 줄이거나 `CARD_HEIGHT` 를 키워야 합니다. **자동으로 안 맞춰집니다.**

### FONT_PATH

```python
FONT_PATH = "assets/malgun.ttf"
```

**한글 폰트를 지정하지 않으면 글자가 네모(□□□)로 나옵니다.** Pillow 의 기본 폰트에는 한글 글자 모양이 들어 있지 않기 때문입니다.

`malgun.ttf` 는 윈도우 기본 폰트(맑은 고딕)를 `C:\Windows\Fonts\` 에서 복사해 온 것입니다. 크기가 13MB 라 커밋할지 말지는 팀에서 정합니다 — 윈도우 쓰는 사람은 각자 복사해도 됩니다.

### BAR_MAX

```python
BAR_MAX = 100    # 능력치가 이 값이면 막대가 꽉 찬다
```

**`STAT_MAX`(99) 와 따로 두는 이유가 있습니다.**

막대 길이를 "그 사람의 능력치 중 제일 큰 값" 기준으로 그리면, 한 능력치만 튀는 사람의 나머지 세 개가 거의 안 보입니다. 고정된 기준값(100)을 쓰면 **사람끼리 막대 길이를 비교할 수 있습니다.** 카드 두 장을 나란히 놓을 때 이게 중요합니다.

## 고칠 때

| 하고 싶은 것 | 만질 값 |
|---|---|
| 레벨이 전체적으로 낮다/높다 | `LEVEL_DIVISOR` |
| 특정 능력치만 너무 크다/작다 | 그 능력치의 `STAT_WEIGHTS` |
| 카드 색 (웹도 같이 바뀜) | `CARD_*` |
| 카드 배치가 겹친다 | `*_TOP`, `STAT_ROW_HEIGHT` |
| 한글이 네모로 나온다 | `FONT_PATH` |

**계수는 기획서에서 확정된 값입니다(2026-08-19). 바꿔야 하면 혼자 고치지 말고 팀에 먼저 알립니다.**

## 확인 방법

값을 바꾼 뒤 눈으로 확인합니다.

```bash
python stats.py     # 레벨이 20~50 사이에 떨어지는지 표로 확인
python card.py      # static/ 에 카드가 생겼는지, 배치가 안 겹치는지
```

## 겪은 함정

- 레벨이 `1~17` 로 나와서 계수가 잘못된 줄 알고 고치려 했는데, 원인은 표본이었습니다. `octocat/Hello-World`(커밋 1개) 같은 장난 저장소만 넣었던 것입니다. 진짜 팀 저장소를 넣으니 `Lv.19~31` 로 정상이었습니다. → **설정을 의심하기 전에 넣은 데이터가 대표성이 있는지 먼저 봅니다.**
